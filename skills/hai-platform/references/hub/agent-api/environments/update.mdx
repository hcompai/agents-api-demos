Updates an existing environment. This is a **full replacement** of the [Browser](/agent-api/environments/browser#configuration) spec. The `id` must match the URL identifier: renames are not supported.

**Returns** the updated [Environment](/agent-api/environments/overview) object.

---

## Path parameters

<ParamField path="id" type="string" required>
  The environment's `id` (e.g. `wide-browser` or `myorg/wide-browser`). Slash-containing identifiers are supported.
</ParamField>

---

## Request body

A **full replacement** of the [Browser](/agent-api/environments/browser#configuration) spec. The `id` in the body must equal the URL identifier. Because this replaces the resource, resend a field's current value to keep it unchanged.

---

## Examples

<CodeGroup>
```bash cURL
curl -X PUT https://agp.eu.hcompany.ai/api/v2/environments/wide-browser \
  -H "Authorization: Bearer $H_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "wide-browser",
    "kind": "web",
    "headless": true,
    "width": 1920,
    "height": 1080,
    "start_url": "https://example.com",
    "mode": "multimodal"
  }'
```

```python Python
from hai_agents import Client

client = Client()  # reads H_API_KEY from the environment

environment = client.environments.update_environment(
    "wide-browser",
    id="wide-browser",
    headless=True,
    width=1920,
    height=1080,
    start_url="https://example.com",
    mode="multimodal",
)
print(environment.mode)
```

```typescript TypeScript
import { HaiAgentsClient } from "hai-agents";

const client = new HaiAgentsClient(); // reads H_API_KEY from the environment

const environment = await client.environments.updateEnvironment({
  id: "wide-browser",
  body: {
    kind: "web",
    id: "wide-browser",
    headless: true,
    width: 1920,
    height: 1080,
    startUrl: "https://example.com",
    mode: "multimodal",
  },
});
console.log(environment.mode);
```

## Errors

| Status | Cause |
|---|---|
| `400` | The `id` in the body does not match the URL identifier (renames are not supported). |
| `403` | The environment is reserved (`h/`) and you are not an H employee. |
| `404` | Environment not found or you don't have access. |
| `422` | Body fails validation; common cases: invalid `id` shape, missing required field. |
