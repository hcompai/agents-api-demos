Retrieves the complete [Session](/agent-api/sessions/overview) object, including the original request, current status, and execution metadata.

Auth is optional: supports public shares.

**Returns** the [Session](/agent-api/sessions/overview) object if the ID is valid and you have access. Returns `404` otherwise.

---

## Path parameters

<ParamField path="id" type="string" required>
  The session ID returned when the session was created.
</ParamField>

---

## Examples

<CodeGroup>
```bash CLI
hai sessions get a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

```bash cURL
curl https://agp.eu.hcompany.ai/api/v2/sessions/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer $H_API_KEY"
```

```python Python
from hai_agents import Client

client = Client()  # reads H_API_KEY from the environment

session = client.sessions.get_session("a1b2c3d4-e5f6-7890-abcd-ef1234567890")
print(session.status.status)
```

```typescript TypeScript
import { HaiAgentsClient } from "hai-agents";

const client = new HaiAgentsClient(); // reads H_API_KEY from the environment

const session = await client.sessions.getSession({
  id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
});
console.log(session.status.status);
```
</CodeGroup>

## Errors

| Status | Cause |
|---|---|
| `404` | Session not found, or you don't have access to it. |

<Tip>
**Use the status endpoint for polling.** If you only need to know whether the session has finished, use [`GET /sessions/{id}/status`](/agent-api/sessions/status) instead. It's lighter and faster.
</Tip>
