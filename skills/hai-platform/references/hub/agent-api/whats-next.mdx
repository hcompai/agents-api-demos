The API ships today with a browser environment. The items below are coming next — no firm dates while the API is in beta.


## Browser profile upload

Bring your own persistent browser state — cookies, local storage, fingerprint — for stealth or for resuming logged-in sessions across runs.

## Desktop environment

A Mac, Windows, or Linux machine the agent can drive end-to-end: file management, native apps, multi-window flows. The same `agent` and `session` lifecycle you use for the browser today, on a different surface.

## Local browser and desktop control

Point a session at a browser or desktop running on **your own machine** instead of a platform-provisioned one. Drive your real, already-logged-in environment locally through the same `agent` and `session` lifecycle, with the CLI bridging the session to the local runtime.
