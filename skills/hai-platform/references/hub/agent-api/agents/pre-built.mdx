List them anytime with [`GET /api/v2/agents`](/agent-api/agents/list):

<CodeGroup>
```bash cURL
curl "https://agp.eu.hcompany.ai/api/v2/agents" \
  -H "Authorization: Bearer $H_API_KEY"
```

```python Python
agents = client.agents.list_agents()
```

```typescript TypeScript
const agents = await client.agents.listAgents();
```
</CodeGroup>

Reference one by name when you create a [session](/agent-api/sessions/overview), and the platform supplies its full configuration:

<CodeGroup>
```bash CLI
hai run "Top 3 stories on Hacker News right now?" \
  --agent h/web-surfer-flash
```

```bash cURL
curl -X POST https://agp.eu.hcompany.ai/api/v2/sessions \
  -H "Authorization: Bearer $H_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent": "h/web-surfer-flash",
    "messages": [{"type": "user_message", "message": "Top 3 stories on Hacker News right now?"}]
  }'
```

```python Python
client.sessions.create_session(
    agent="h/web-surfer-flash",
    messages=[{"type": "user_message", "message": "Top 3 stories on Hacker News right now?"}],
)
```

```typescript TypeScript
await client.sessions.createSession({
  body: {
    agent: "h/web-surfer-flash",
    messages: [{ type: "user_message", message: "Top 3 stories on Hacker News right now?" }],
  },
});
```
</CodeGroup>
